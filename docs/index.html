Что умеет

  • 01

    Таймер над полем ввода

    Пока Claude работает, секунды тикают: «Идёт: 0:42 · Сессия: 4:22». Закончил — видно, сколько длился последний ответ.

  • 02

    Токены и деньги за ход

    Все четыре счётчика API: ввод, вывод, чтение и запись кэша, вместе с субагентами. Стоимость — как в /cost.

  • 03

    История запросов

    /time или кнопка «История» — список запросов сессии со временем, токенами и суммой. После перезапуска и --resume она на месте.

  • 04

    Сегодня и этот месяц

    Суммы по всем сессиям на компьютере — в полосе и в панели, с первой секунды сессии.

  • 05

    Отчёт по дням

    Файл costs.md: деньги, число запросов и время по дням и месяцам. Обычный Markdown.

  • 06

    Русский и английский

    Язык подписей — по языку системы. Переключается в настройках мода.

Сколько стоил каждый запрос

Панель «Время по запросам» показывает всю сессию: время, токены и сумму каждого запроса, итог и разбивку токенов. Прерванные запросы помечены.

Установка

  1. Добавьте marketplace

    В Claude Code — в терминале или в поле ввода десктопного приложения:

    /plugin marketplace add KotovDima1C/tickturn

  2. Установите мод

    Выберите область user — тогда мод работает во всех проектах.

    /plugin install tickturn@tickturn

  3. Перезапустите Claude Code

    Полоса появится над полем ввода с первым запросом. История — по команде /time.

Можно и проще: попросите Claude «Установи мод tickturn из KotovDima1C/tickturn» — он выполнит обе команды сам.

Как устроено

Мод — модуль хуков Claude Code. Время хода берёт у движка, токены — из ответов API, стоимость — из того же счётчика, что /cost. На подписке это оценка по тарифам API, а не реальное списание.

Данные лежат у вас в ~/.claude/tickturn/: файл истории на каждую сессию и отчёт costs.md. В сеть мод ничего не отправляет.
